DreamRole: AI-Driven Skill-Gap Analysis & Career Readiness Platform

An End-to-End Artificial Intelligence Platform for Automated Skill Extraction, Rubric JD Gap Analysis, and STAR Speech Interview Simulation

AI / NLP / HR-Tech / EdTech
Microservice REST API + SPA
Netlify (FE) & Render (BE)

1. Abstract & Executive Summary

The modern hiring ecosystem relies heavily on automated Applicant Tracking Systems (ATS) and strict technical rubrics. College graduates and job candidates frequently experience high rejection rates due to unstructured resume formatting, missing technical keywords, and a lack of objective, real-time interview practice. DreamRole addresses this gap by offering a unified, web-based AI platform that extracts candidate skills, performs a weighted 4-tier Job Description (JD) gap analysis, simulates realistic speech/video interviews with STAR-framework evaluation, and generates customized learning roadmaps.

2. Problem Statement

  • High ATS Rejection Rates: Candidates are filtered out automatically due to uncalibrated terminology or missing keyword density.
  • Unclear Skill Gaps: Job seekers lack visibility into which specific technical competencies or projects are missing for a target job role.
  • Interview Performance Anxiety: Traditional preparation lacks realistic technical and behavioral interview practice with immediate, structured feedback.

3. Role of Natural Language Processing (NLP) & AI Stack

NLP / AI Capability Underlying Technology Function in DreamRole System
Named Entity Recognition (NER) OpenAI NLP + Custom Regex Normalizer Extracts technical tools, frameworks, and programming languages from raw PDF resumes; normalizes variants (e.g., *"ReactJS"* → *"React"*).
Semantic Similarity Matching Vector Contextual Matching Engine Compares JD terms against candidate skills. Detects Adjacent Matches (e.g., candidate knows *"GCP"* when JD requires *"AWS"*).
Automatic Speech Recognition (ASR) OpenAI Whisper API (`whisper-1`) Transcribes live spoken audio during video interviews with 98%+ precision on technical jargon (*Kubernetes*, *PostgreSQL*, *CI/CD*).
Text-to-Speech (TTS) Synthesis OpenAI Speech API (`tts-1`) Generates realistic human voice audio (`nova` voice) for the AI Interviewer question readout.
STAR Framework Evaluation GPT-4o-mini Rubric Evaluation Model Grades interview answers on 4 dimensions (Technical Accuracy 40%, Specificity 25%, Clarity 20%, Relevance 15%) and generates HR Re-framed Model Answers.

4. Key Functional Modules

Module Name Technical Description & User Outcome
1. Resume Skill Extractor Parses raw PDF/DOCX resumes using `pdf-parse`, extracts named skills, tools, and projects, and builds a structured profile snapshot.
2. Rubric JD Gap Analyzer Evaluates resumes against JDs using a weighted 4-tier rubric. Identifies hard disqualifiers, missing keywords, formatting issues, and actionable non-fabricating suggestions.
3. AI Video & Speech Interview Engine Simulates live video interviews, records candidate speech, transcribes with Whisper, and evaluates response structure using the STAR method with HR re-framed answers.
4. Adaptive Testing & Roadmaps Generates targeted MCQs based on identified missing skills and creates 5-7 step step-by-step career path roadmaps.
5. Mentor & Analytics Dashboard Tracks student progress, speech metrics (WPM, volume, pauses, filler words), overall readiness scores, and session histories.

7. Key System Innovations & Conclusion

  • Honesty-Guarded AI Engine: Prevents resume language fabrication by framing missing skills as projects/courses to acquire.
  • Hybrid Speech Pipeline: Merges real-time browser typing animation with server-side OpenAI Whisper transcription for 98%+ technical term accuracy.
  • Structured HR Re-Framing: Teaches candidates how senior engineers and HR managers structure technical answers.
